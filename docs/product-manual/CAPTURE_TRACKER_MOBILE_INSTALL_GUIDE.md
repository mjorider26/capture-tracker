# Capture Tracker Mobile Installation Guide

Capture Tracker is accessed in the browser; it is not an App Store or Play Store app. Open the production URL supplied by the workspace owner.

- **iPhone / Safari:** Share → Add to Home Screen → Add.
- **Android / Chrome:** menu → Add to Home screen.

The resulting icon is a browser shortcut and does not guarantee offline use. Confirm the production URL before entering business data; staging and local demo are fictional-only environments.

For receipt capture, open Documents → Take photo and allow the browser’s camera permission. If the camera does not open, confirm permission and HTTPS, then select an existing PDF/JPEG/PNG instead. Camera photos are normalized on the phone before the existing private upload. After upload, the document stays private while its security scan is pending and then refreshes automatically to Ready, rejected, or a safe scan-failure message. Only Ready documents can be opened or used as evidence.
