# Capture Tracker Account Access Guide

Capture Tracker production is a private workspace. The first owner can complete a one-time bootstrap only before the workspace is initialized; after that, public Create account is intentionally closed. Existing users sign in with their assigned email and password at the owner-supplied URL.

If Create account is missing, this is expected for an initialized workspace. Ask the workspace owner to arrange access. Do not use staging invitations or local-demo access procedures for production. There is no current self-service password reset or email-verification recovery flow; contact the owner for help. Sign out when finished and sign back in to confirm access on a new device.
