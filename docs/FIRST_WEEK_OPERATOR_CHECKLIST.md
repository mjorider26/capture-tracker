# First-week operator checklist

Use the operator status page and production operations records. Do not copy customer financial data into this checklist.

## Every day, days 1–7

- Confirm live and ready health checks, current release, migration state, and last verified backup.
- Review failed authenticated requests, import failures, posting failures, reconciliation blockers, document scan failures, and any safely available queue/DLQ signal.
- Confirm invitation delivery status through the approved manual-link process while transactional email is not configured.

## Day 1

- Confirm the client can sign in, install the PWA, access Today, and complete the guided setup path.
- Confirm no session/authentication boundary regressions are present.

## Day 2

- Confirm the client can use example CSV templates and understands preview, duplicate review, and posting boundaries.
- Check that document scan delay/failure messages give a safe next action.

## Day 3

- Confirm the client has completed a first import through the supported workflow.
- Confirm Weekly Review is understood and identify unresolved setup blockers.

## Day 4–6

- Review readiness for reconciliation, Owner Money, payroll context, fixed assets, and month-close blockers.
- Capture first-client feedback without requesting financial values or document contents.

## Day 7

- Review books-current-through status, initial reconciliation, Owner Money exceptions, payroll context, and unresolved CPA-review items.
- Review feedback, verify backup status, and record the current release/build in the operator handoff.
